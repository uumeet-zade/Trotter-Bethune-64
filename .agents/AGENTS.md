# Copywriting and Style Rules

- **No em dashes:** Do not use em dashes (—) in any copy, UI text, or conversational responses. Use other punctuation or structure sentences differently.
- **No "Is not X, but Y" phrasing:** Absolutely avoid using structures like "is not X, but Y" or "is X, not Y" (e.g., "This is not about negotiation, it is about restoration"). State the affirmative directly and forcefully (e.g., "This demands absolute restoration").
